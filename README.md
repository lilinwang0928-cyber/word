# 國學思辨互動學習單（筆筆陪寫）

墨筆小精靈「筆筆」陪伴國中生寫作的單檔互動學習單。

**線上使用：** https://lilinwang0928-cyber.github.io/word/

## 章節（4 組 13 章）
- **筆筆陪寫**：陪寫路線、寫作稿紙、批閱檢核、筆筆小語
- **寫作基本功**：標點符號、標點練習、修辭詞語、成語佳句
- **單元課程**：作文單元（初／中／高級各 20 單元）、破冰課（車票與月台 40 分鐘）
- **秋日課程**：課程地圖、秋日書單、文言經典

## 說明
- 單一 `index.html`，不需安裝；學生資料存在各自瀏覽器，可用頁面上的「匯出・匯入」備份碼換裝置。
- 名言佳句選自國立暨南國際大學圖書館「歷年名言佳句」；成語詳細出處請查教育部《成語典》。
- `icons/`：筆筆 APP 圖示（512／192／180／64／32）。
